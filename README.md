# @opinionated-ts/write-once-github

Official GitHub repository integration for [write-once](https://github.com/opinionated-ts/write-once).

This package is under development. Its repository reference syntax, ref resolution behavior, and public API will be documented here as the integration is implemented.

## Development

```sh
bun install
bun test
bun check
bun build
```

- [write-once](https://github.com/opinionated-ts/write-once) — core resource preparation, resolution, and content extraction pipeline.
